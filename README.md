# 荒原小队

一个面向局域网的多人 2D 横版生存乱斗网页游戏。服务端采用权威状态同步，玩家只发送输入，移动、战斗、敌人和胜负均由服务端计算。

## 功能

- 创建、搜索、邀请码加入房间，支持 2–8 人
- 合作 PvE：5 个逐渐增强的怪物波次，波次之间有和平时间用于逛商店
- 无尽模式：波次无限递进（伤害、血量、刷新速度、Boss 频率随波次成长），每清空一波自动存档，可随时手动存档
- 账号系统：注册 / 登录 / 改密 / 注销，记录出战、胜场、击杀、最高波次与累计时长
- 存档点：服务器把无尽进度写入 `data/saves.json`，建房时可以选择存档点继续，未参与的玩家按波次获得加入补偿
- 服务器数据备份：随时导出全部账号与存档为明文 JSON，可在新服务器一键导入还原
- 多人 PvP：自动锁定射击、最后存活者获胜
- 横版移动、跳跃（含二段跳）、平台碰撞和镜头跟随
- 4 个职业：突击手、守卫、医师、游侠，各自拥有 E 键主动技能
- 类幸存者游戏成长：自动攻击、经验升级、三选一强化、穿透/暴击/护甲/自愈
- 升级条目带稀有度等级（普通/稀有/史诗/传说），可多次选择直至满级
- 武器与道具系统：7 种武器、14 种被动道具，可由敌人掉落或商店购买
- 金币、商店（自我升级 + 购买武器/道具）、背包、精英怪、Boss 和宝箱掉落
- 敌人掉落经验球、金币，以及武器/道具；Boss 掉落宝箱
- 程序化生成的地图：随机平台、塔楼、立柱与岩石装饰
- 房主迁移、断线清理、15Hz 状态广播、30Hz 权威游戏循环
- Canvas 网页客户端，无需安装客户端

## Windows 启动

1. 安装 [Node.js 20 LTS](https://nodejs.org/) 或更高版本。
2. 解压项目后双击 `start-windows.bat`。
3. 第一次启动会自动执行 `npm install`。
4. 如果 Windows 防火墙弹窗询问，选择允许“专用网络”访问。
5. 开服电脑访问 `http://localhost:3000`，其他同局域网设备访问终端打印的 `局域网访问` 地址。

如果没有弹出防火墙提示，可用管理员 PowerShell 执行一次：

```powershell
New-NetFirewallRule -DisplayName "Lan Battle 3000" -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow -Profile Private
```

也可以右键 `start-windows.ps1` 选择“使用 PowerShell 运行”。如果系统阻止脚本，可在当前窗口执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start-windows.ps1
```

## 通用启动

要求 Node.js 20 或更高版本。

```bash
npm install
npm start
```

服务默认监听所有网卡的 `3000` 端口，并在终端打印可用地址。

- 开服电脑访问：`http://localhost:3000`
- 同一局域网设备访问：`http://<开服电脑局域网IP>:3000`

如果其他设备无法访问，请允许 TCP `3000` 端口通过系统防火墙。可通过环境变量修改监听配置：

```bash
HOST=0.0.0.0 PORT=8080 npm start
```

启动后终端会打印数据目录与管理密钥（用于备份导出/导入还原）：

```text
LAN Battle 已启动: http://localhost:3000
数据目录（明文存储）: /path/to/project/data
管理密钥（用于备份导出/导入还原）: 3e911941f588855e66cd8f39
```

其它可选环境变量：

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| `DATA_DIR` | 数据目录（明文账号、存档、备份） | `./data` |
| `ADMIN_KEY` | 固定管理密钥，不设置则首次启动随机生成 | 随机 |
| `AUTO_BACKUP_MINUTES` | 自动快照间隔（分钟），`0` 表示关闭 | `30` |

## 操作

- `A` / `D` 或方向键：左右移动
- `W` / `空格` / 上方向键：跳跃，空中可再次按下进行二段跳
- `E`：释放职业主动技能
- `Tab`：打开/关闭商店
- `B`：打开/关闭背包
- 无尽模式房主可用 HUD 上的「💾 保存进度」手动存档
- 武器自动锁定射程内最近目标并攻击
- 拾取绿色能量球升级，每次升级在带品质等级的三项强化中选择一项
- 拾取金币、宝箱、武器与道具（敌人掉落），在和平时间打开商店购买恢复或永久强化

| 职业 | 定位 | 主动技能 |
| --- | --- | --- |
| 突击手 | 均衡输出 | 弹幕爆发：朝最近目标或面朝方向连射 8 发弹丸 |

## 账号与无尽模式存档

大厅右下角的「账号与存档」面板提供账号功能：

1. 填写账号名（2–16 位中文/字母/数字/下划线/短横线）和密码（4–64 位），点击「注册新账号」或「登录」。
2. 登录后浏览器只保存登录令牌，昵称自动使用账号显示名；刷新页面、断线重连都会自动恢复登录状态。
3. 面板中会显示出战、胜场、击杀、最高波次、无尽最高波次和累计时长，并可修改密码或注销账号（注销会一并删除存档）。
4. 修改密码、注销账号或导入他人数据后，旧登录令牌立即失效，旧页面会收到提示并要求重新登录。
5. 连续登录失败会锁定 30 秒；锁定按账号名与来源地址记录，重连或换页面都不会绕过。

无尽模式（建房时选择「无尽模式」）的存档流程：

- 每清空一波进入和平时间时，服务器自动把整局进度写入存档（含地图、波次、每位玩家的等级/金币/武器/道具/强化）。
- 房主在对局中可随时点击 HUD 上的「💾 保存进度」，或在房间面板中选择/删除存档点。
- 再次建房时（无尽模式）选择某个存档点，全队将从该波次继续；存档中不存在的玩家会按波次获得加入补偿。
- 对局结束时该存档会标记为「已结束」并保留在历史列表里，但不能再用于续玩；开始新一轮会从头出发。
- 全员掉线（刷新页面、断网、房主电脑睡眠）不会判定失败，也不会封存存档：
  此时对局会**冻结**（不推进时间、波次与自动存档，避免空房间自己刷到高波次），重连即继续；
  席位超时后仍能用存档点重新开局。
- 存档不保存敌人：若存档点停在 Boss 波的战斗阶段，续玩时会自动补刷该波 Boss。
- 只有登录账号的房主可以保存进度，存档归属该账号；房主退出登录或换号后，房间会立即释放原存档点，其他账号无法读取或使用。

## 服务器数据备份与迁移

所有服务器数据都以**明文 JSON** 保存在 `data/` 目录（可用 `DATA_DIR` 环境变量修改）：

```text
data/
  accounts.json   账号（含明文密码）、登录令牌
  saves.json      无尽模式存档点
  server.json     服务器实例信息、管理密钥、备份历史
  backups/        自动 / 手动快照，每次导入前也会自动快照
```

> ⚠️ 按需求所有信息（包括密码、登录令牌、存档）都是明文保存，方便整机迁移与人工导出。
> 因此请只在可信的局域网内运行本服务，不要把 3000 端口或 `data/` 目录暴露到公网。

管理密钥在首次启动时随机生成并打印在终端，也可用 `ADMIN_KEY` 环境变量指定。网页端的
「服务器数据备份 / 导入还原」面板（需要管理密钥）支持：

- **数据概览**：账号数、存档数、数据目录、最近备份、本地快照列表
- **导出备份**：下载 `lan-battle-backup-<时间>.json`（含账号、令牌、存档，可在新服务器导入）
- **立即快照**：在 `data/backups/` 生成一份快照，可随时下载或用「还原」按钮回滚
- **导入备份**：`覆盖还原` 会替换现有账号与存档，`合并导入` 会按账号名/存档 ID 合并；导入前自动快照原数据
- 同一账号在两台服务器上的内部 id 可能不同：导入时会自动把存档与登录令牌重映射到本机账号，
  并清理没有归属账号的孤立存档（报告中显示为「覆盖清理 / 清理孤立」）

同样的能力也可以在命令行离线使用（服务器未启动时也能操作数据文件）：

```bash
npm run data:info                       # 查看数据目录、数量与管理密钥
npm run backup -- my-backup.json        # 导出备份（默认 lan-battle-backup-<时间>.json）
npm run restore -- my-backup.json       # 覆盖还原
node src/cli.js import my-backup.json --merge   # 合并导入
node src/cli.js backups                 # 列出本地快照
node src/cli.js restore <快照文件名>     # 用本地快照还原
```

HTTP 接口（`x-admin-key` 请求头或 `?key=` 查询参数）：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/admin/info` | 数据概览与快照历史 |
| GET | `/api/admin/export` | 下载完整备份 |
| POST | `/api/admin/import?mode=replace\|merge` | 导入还原（请求体为备份 JSON） |
| POST | `/api/admin/backup` | 立即生成快照 |
| GET | `/api/admin/backups` | 列出本地快照 |
| GET | `/api/admin/backups/:file` | 下载指定快照 |
| POST | `/api/admin/restore-backup` | 用本地快照还原（`{ file }`） |

**换服务器**：在新机器上启动服务（会生成新的管理密钥）→ 打开备份面板填入新密钥 →
导入旧服务器的备份文件（覆盖还原）→ 账号、密码、登录令牌与存档全部恢复。

## 服务端协议

Socket.IO 客户端连接后可使用以下事件：

| 方向 | 事件 | 数据 |
| --- | --- | --- |
| 客户端 → 服务端 | `room:create` | `{ playerName, classId, roomName, mode, maxPlayers, saveId? }` |
| 客户端 → 服务端 | `room:join` | `{ playerName, classId, code }` |
| 客户端 → 服务端 | `room:ready` | `{ ready }` |
| 客户端 → 服务端 | `room:set-save` | `{ saveId }`（房主选择存档点，`null` 为从头开始） |
| 客户端 → 服务端 | `game:start` | 无 |
| 客户端 → 服务端 | `save:now` | 无（房主手动保存无尽进度） |
| 客户端 → 服务端 | `game:input` | `{ left, right, jump, skill }` |
| 客户端 → 服务端 | `upgrade:choose` | 强化 ID |
| 客户端 → 服务端 | `shop:buy` | 商品 ID |
| 客户端 → 服务端 | `account:register` | `{ username, password, displayName? }` |
| 客户端 → 服务端 | `account:login` | `{ username, password }` |
| 客户端 → 服务端 | `account:auth` | `{ token }`（用令牌恢复登录） |
| 客户端 → 服务端 | `account:password` / `account:rename` / `account:delete` | 修改密码 / 显示名 / 注销账号 |
| 客户端 → 服务端 | `account:delete-save` | `{ saveId }` |
| 服务端 → 客户端 | `room:state` | 完整房间状态（含存档点信息） |
| 服务端 → 客户端 | `game:start` | 地图、模式与是否为存档续玩 |
| 服务端 → 客户端 | `game:snapshot` | 玩家、敌人、弹丸、掉落状态 |
| 服务端 → 客户端 | `upgrade:choices` | 三个强化选项 |
| 服务端 → 客户端 | `account:session` | `{ token, account, saves }` |
| 服务端 → 客户端 | `account:saves` | 该账号的存档列表 |
| 服务端 → 客户端 | `game:event` | 波次、和平时间、技能、掉落、`saved`（已保存进度）等提示 |
| 服务端 → 客户端 | `game:end` | 胜负结果（无尽模式含到达波次） |

需要回执的房间操作采用 Socket.IO acknowledgement，格式为 `{ ok, room?, session?, error? }`。

## 无尽模式数值

| 项目 | 规则 |
| --- | --- |
| 战斗时长 | 30 秒起，每波 +2 秒，上限 50 秒 |
| 和平时间 | 15 秒起，每波 −0.6 秒，下限 7 秒（商店开放、自动存档） |
| 敌人血量 | 每波 +33%，第 8 波后额外每波 +12% |
| 敌人速度 / 伤害 | 每波 +9 / +2.4 |
| 刷新速度 | 每秒 `0.8 + 0.42 × 波次`，上限 6 只/秒 |
| 同屏上限 | `8 + 6 × 波次`，上限 96 只 |
| Boss | 每 5 波刷新，第 10 波后数量随波次增加 |
| 中途加入补偿 | 每波 +5% 生命/伤害（上限 ×1.6）、金币与三选一强化 |
| 商店开放 | 与固定波次一致，仅在和平时间可购买 |
| 无人连接 | 全员掉线时对局冻结，不推进波次也不写入存档 |

```text

  server.js          HTTP 与 Socket.IO 入口
  room-manager.js    房间生命周期、存档点与账号绑定
  game.js            权威游戏循环、战斗逻辑、无尽模式与存档序列化
  config.js          游戏数值、无尽成长曲线与强化池
  store.js           明文数据存储（账号 / 存档 / 备份导出导入）
  account-service.js 账号注册登录、令牌与存档列表推送
  admin-api.js       备份导出/导入还原 HTTP 接口
  cli.js             离线备份命令行工具
public/
  index.html         大厅、房间、账号与备份界面
  client.js          输入、网络同步、账号/存档/备份操作与 Canvas 渲染
test/                核心房间、游戏、无尽模式、存档与数据存储测试
```
